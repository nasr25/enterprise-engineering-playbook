# Database Engineering Review Checklist

- **DB-156** — Confirm platform choice, ownership, source of truth, workload model, growth assumptions, data classification, RPO, and RTO are documented.
- **DB-157** — Confirm keys, relationships, constraints, nullability, indexes, query plans, pagination, and transaction boundaries preserve integrity and performance.
- **DB-158** — Confirm migrations, backfills, compatibility, rollback, retention, deletion, audit, backup, restore, failover, and disaster recovery are tested.
- **DB-159** — Confirm encryption, secrets, least privilege, network controls, privileged access, masking, tenant isolation, and security monitoring meet policy.
- **DB-160** — Confirm observability, capacity, maintenance, runbooks, support ownership, data quality, lineage, and operational acceptance are complete before production approval.

## Required Evidence

A production database review should include the logical model, physical model, data dictionary, representative execution plans, growth forecast, privilege matrix, migration plan, backup and restore evidence, DR evidence, monitoring dashboard, alert definitions, retention schedule, and support runbook.

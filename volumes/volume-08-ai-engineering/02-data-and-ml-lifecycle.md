# Data and ML Lifecycle

- **AI-021 — Data Provenance:** Training, tuning, evaluation, and retrieval data MUST have traceable origin and ownership.
- **AI-022 — Authorized Data:** Data MUST be legally and organizationally authorized for its intended AI use.
- **AI-023 — Data Minimization:** Only data required for the defined purpose SHOULD be collected or processed.
- **AI-024 — Data Classification:** AI datasets MUST inherit enterprise data classification and handling requirements.
- **AI-025 — Sensitive Data Controls:** Sensitive fields MUST be removed, masked, tokenized, or otherwise protected when not essential.
- **AI-026 — Dataset Versioning:** Material datasets MUST be versioned or reproducibly identifiable.
- **AI-027 — Reproducible Splits:** Training, validation, and test splits MUST be reproducible and protected against leakage.
- **AI-028 — Leakage Prevention:** Feature, target, temporal, and cross-user leakage MUST be explicitly tested.
- **AI-029 — Data Quality:** Completeness, validity, consistency, duplication, and distribution MUST be measured for critical datasets.
- **AI-030 — Representativeness:** Dataset representativeness and known coverage gaps MUST be documented.
- **AI-031 — Label Governance:** Label definitions, sources, quality checks, and disagreement handling MUST be documented.
- **AI-032 — Data Lineage:** Transformations from source data to model-ready data MUST be traceable.
- **AI-033 — Feature Definitions:** Critical engineered features MUST have stable definitions and ownership.
- **AI-034 — Time Correctness:** Time-dependent models MUST prevent future information from contaminating historical training or evaluation.
- **AI-035 — Retention:** AI data retention MUST follow approved retention and deletion requirements.
- **AI-036 — Deletion Propagation:** Required deletion MUST be considered across source datasets, derived datasets, indexes, caches, and retraining workflows.
- **AI-037 — Synthetic Data:** Synthetic data MUST be labeled as synthetic and validated for privacy and statistical suitability.
- **AI-038 — Data Drift:** Production systems MUST define monitoring for meaningful input or feature distribution drift where applicable.
- **AI-039 — Pipeline Reproducibility:** Material preprocessing and feature pipelines MUST be automated and reproducible.
- **AI-040 — Dataset Documentation:** Critical datasets MUST include documentation of purpose, provenance, limitations, sensitivity, quality, and lifecycle.

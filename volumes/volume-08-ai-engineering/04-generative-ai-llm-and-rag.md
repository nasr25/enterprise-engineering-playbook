# Generative AI, LLM, and RAG

- **AI-061 — Task Definition:** Generative AI tasks MUST define expected output, unacceptable output, and downstream use.
- **AI-062 — Prompt Versioning:** Production system prompts and material prompt templates MUST be version-controlled.
- **AI-063 — Prompt Separation:** System instructions, developer-controlled context, user input, and retrieved content MUST remain logically separated.
- **AI-064 — Untrusted Instructions:** Content from users, documents, websites, email, or tools MUST be treated as untrusted data, not privileged instructions.
- **AI-065 — Prompt Injection Testing:** LLM applications MUST be tested for direct and indirect prompt injection.
- **AI-066 — Output Validation:** Machine-consumed LLM output MUST be schema-validated and rejected safely on invalid structure.
- **AI-067 — No Blind Execution:** Generated commands, code, queries, URLs, or actions MUST NOT be executed solely because the model produced them.
- **AI-068 — Grounding:** Applications requiring factual enterprise answers SHOULD ground responses in authoritative sources.
- **AI-069 — Source Traceability:** RAG systems SHOULD retain sufficient source metadata to identify the evidence used for an answer.
- **AI-070 — Retrieval Authorization:** Retrieval MUST enforce the caller's authorization before content reaches the model.
- **AI-071 — No Permission Bypass:** Vector similarity or search ranking MUST NOT bypass document-, tenant-, record-, or user-level access controls.
- **AI-072 — Chunking Evaluation:** Chunking, overlap, metadata, and retrieval strategy MUST be evaluated against representative queries.
- **AI-073 — Embedding Governance:** Embedding models and vector indexes MUST be versioned and included in change management.
- **AI-074 — Index Freshness:** RAG systems MUST define synchronization, deletion, and freshness behavior for indexed content.
- **AI-075 — Retrieval Quality:** Retrieval quality MUST be evaluated separately from generation quality.
- **AI-076 — Hallucination Evaluation:** Factual use cases MUST measure unsupported or fabricated claims using representative tests.
- **AI-077 — Abstention:** High-risk factual assistants SHOULD be able to abstain or state insufficient evidence rather than invent an answer.
- **AI-078 — Citation Integrity:** When citations are shown, the system MUST verify that cited sources actually support the associated claim to the practical extent possible.
- **AI-079 — Context Limits:** Context-window limits, truncation, ordering, and lost-context behavior MUST be tested.
- **AI-080 — Structured Output:** Structured interfaces SHOULD use constrained or schema-based generation where supported.
- **AI-081 — Model Routing:** Routing between models MUST be policy-controlled and MUST preserve data classification and residency requirements.
- **AI-082 — Provider Failover:** Failover MUST NOT silently move protected data to an unapproved provider or region.
- **AI-083 — Content Controls:** Required safety, policy, and domain controls MUST be applied independently of model helpfulness.
- **AI-084 — LLM Evaluation Set:** Production LLM applications MUST maintain a regression evaluation set covering core tasks, failure cases, and adversarial inputs.
- **AI-085 — Prompt and RAG Regression:** Model, prompt, retrieval, embedding, chunking, or tool changes MUST trigger relevant regression evaluation before release.

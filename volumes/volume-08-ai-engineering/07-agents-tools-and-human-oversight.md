# Agents, Tools, and Human Oversight

- **AI-136 — Bounded Autonomy:** Agent autonomy MUST be explicitly bounded by task, permissions, resources, time, and allowed tools.
- **AI-137 — Tool Allowlist:** Agents MUST use an explicit allowlist of approved tools and actions.
- **AI-138 — Tool Authorization:** Tool execution MUST enforce authorization independently of the model's request.
- **AI-139 — Parameter Validation:** Tool parameters produced by models MUST be validated before execution.
- **AI-140 — Confirmation for High Impact:** Destructive, financial, privileged, externally visible, or otherwise high-impact actions MUST require appropriate confirmation or approval.
- **AI-141 — Read Before Write:** Agents SHOULD prefer read/inspect operations before mutation when resolving uncertainty.
- **AI-142 — Least-Privilege Identity:** Agent identities MUST NOT inherit broad administrator privileges merely for convenience.
- **AI-143 — Separation of Duties:** Critical workflows SHOULD separate recommendation, approval, and execution where risk warrants it.
- **AI-144 — Action Audit:** Agent tool calls MUST record actor, tool, parameters or safe representation, result, and relevant correlation identifiers.
- **AI-145 — Loop Limits:** Agents MUST have bounded iterations, tool calls, execution time, and resource consumption.
- **AI-146 — Failure Stop:** Repeated tool failures or inconsistent state MUST trigger safe termination or human escalation.
- **AI-147 — State Verification:** Agents MUST verify consequential state changes rather than assuming tool success.
- **AI-148 — External Content:** Tool outputs and browsed content MUST be treated as potentially malicious or instruction-bearing data.
- **AI-149 — Human Escalation:** Agents MUST define conditions requiring transfer to an authorized human.
- **AI-150 — Approval Context:** Human approvers MUST receive enough context to understand the proposed action and material consequences.
- **AI-151 — No Approval Fatigue:** Systems SHOULD group or prioritize approvals so human oversight remains meaningful.
- **AI-152 — Reversibility:** Automated actions SHOULD be reversible where practical, with compensating actions documented when not.
- **AI-153 — Memory Boundaries:** Agent memory MUST NOT silently cross users, tenants, projects, or security contexts.
- **AI-154 — Delegation Boundaries:** An agent MUST NOT delegate privileges to another agent or service beyond its own authorized scope.
- **AI-155 — Agent Evaluation:** Agent testing MUST evaluate task success, tool correctness, unauthorized actions, loops, recovery, and human handoff.

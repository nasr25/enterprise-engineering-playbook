## Rule Namespace

Rules in this volume use the `DO` prefix. The completed rule set covers `DO-001` through `DO-180`.

## Core Position

Delivery automation and platform engineering are production control systems. They must be secure, reproducible, observable, recoverable, and governed with the same rigor as application code.

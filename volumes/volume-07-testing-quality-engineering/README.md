# Volume 07 — Testing & Quality Engineering

## Purpose

Define technology-neutral standards for verification, validation, quality governance, test automation, release confidence, and continuous improvement across software delivery.

## Scope

These standards apply to requirements, source code, APIs, user interfaces, databases, integrations, infrastructure, mobile applications, operational processes, and production releases.

## Rule Namespace

Rules in this volume use the `TST` prefix. The completed rule set covers `TST-001` through `TST-180`.

## Core Position

Quality is engineered throughout the lifecycle. Testing provides evidence about risk; it does not replace sound architecture, secure coding, observability, or accountable decision-making.
